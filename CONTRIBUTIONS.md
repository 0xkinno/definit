# Contributions

## What is original

DEFINIT's contribution is a contract-level execution boundary built out of a
property that already exists in the sponsor's network but is not, on its own,
an enforcement mechanism.

The published surface describes storage scopes as a way to *read* a decision.
DEFINIT turns the difference between those scopes into the thing that
*authorises an irreversible effect*. Concretely, this submission contributes:

1. **A precise statement of the defect.** A decision becomes readable before it
   stops being reversible, so any integration that treats "readable" as
   "settled" has a window in which it can act on a judgment that is later
   overturned. The defect is stated as a falsifiable claim with named
   falsifiers in `docs/LIMITATIONS.md`.

2. **A commitment binding that survives the boundary.** The effect is not
   authorised by an identifier alone. The gate records a canonical commitment
   over beneficiary, amount, asset, policy hash, evidence digest, nonce and
   deadline; the vault requires the caller to reproduce every field, and
   compares them field by field before value moves. An identifier that points
   at the right decision but the wrong beneficiary is refused.
   Implementation: `contracts/decision_gate.py`, `contracts/finality_vault.py`,
   mirrored in TypeScript in `lib/commitments/commitment.ts`.

3. **A finality-gated capability, not a finality-aware check.** The gate exposes
   `get_capability`, which answers differently depending on the storage scope it
   is read at. The vault never reads it at provisional scope. The read scope is
   published by `describe()` on chain so the property can be verified by a third
   party without reading the source.

4. **A baseline that isolates the variable.** `contracts/control/unsafe_release.py`
   is the same settlement contract with exactly one property removed: it
   consults the provisional scope. Comparing the two arms is therefore
   attributable to that one difference rather than to a rewrite.

5. **A corpus with acceptance cases.** Twelve cases, three of which must
   *succeed*. A guard that refuses everything fails the corpus, which is what
   makes the refusal count meaningful.

6. **An isolation discipline that is executable.** `scripts/audit-isolation.mjs`
   fails the build if survey vocabulary or any surveyed project name appears in
   the shipped tree. Field research lives in `research/`, which is gitignored.

7. **A reproduction path that does not need trust.** Every headline number is
   generated by a command into `docs/evidence/`, and every document that quotes
   a number points at the generator rather than restating it.
